# Orbit product model

Orbit is a single learning workspace for learners and teachers. Everyone uses the same account and sign-in. A user may be a learner in one class, the admin of another, and a teacher for selected subjects in a third.

## Class permissions

- Any signed-in user can create a class; the creator becomes its class admin.
- The class admin can assign existing Orbit users as teachers for specific subjects, remove subject assignments, and transfer class ownership to another member.
- Joining a class adds learner access. Class-specific membership controls permissions; there is no separate teacher login or user-selected role.
- Class admins manage their class. Subject-assigned teachers create and grade assignments for their assigned subjects. Learners see only their own returned grades.

## Feature areas

- **Authentication and profile:** Firebase email/password and Google sign-in, verified email, password recovery, onboarding, username, and avatar selection.
- **Classrooms:** class creation/join, admin controls, teacher assignments by subject, announcements, and resources.
- **Assignments:** due dates, written responses, files, objective quizzes, subject-scoped teacher review, and returned feedback.
- **Grades:** learner-private returned grades and class/subject-scoped teacher gradebook access. Objective quiz scores are suggestions until a teacher returns them.
- **Coding ground:** restricted interpreter for introductory Python, not general-purpose execution.
- **Study space:** AI explanations and practice support through a configurable provider.
- **Academic tools:** local PDF reading, image-to-PDF, note editing, and document export.
